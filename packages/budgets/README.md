# Shell and PWA install-size budgets

This package defines **demonstration** install-size gates for the App's shell and
precached assets. Its fixture sizes are invented, **not** measurements from a
local Vite production build; no production build was run for this lane.
The fixture lists individual paths, uncompressed bytes, and kinds. Totals
include each listed asset once; JavaScript includes Workbox files, while the
largest JS entry checks only assets explicitly typed `js`. The fixture is not
a complete Workbox-generated precache manifest and must not be mistaken for one.

| Budget | Maximum (bytes) | Rationale |
| --- | ---: | --- |
| Total precached install | 3,145,728 (3 MiB) | Keep initial offline shell transfer bounded |
| Largest JS entry | 524,288 (512 KiB) | Flag oversized entry chunks |
| Total JS including Workbox | 1,572,864 (1.5 MiB) | Limit script transfer |
| Total CSS | 262,144 (256 KiB) | Limit stylesheet transfer |
| Each asset | 786,432 (768 KiB) | Catch unexpectedly large individual files |

These are **proposed targets**, not observed performance benchmarks. They apply
to the shell-plus-assets install, **not** offline map datasets: map tiles are
not stored in the current shell. Runtime-cached content is not included in
the precache fixture. These budgets use **uncompressed bytes** and do not
estimate network transfer or execution time. Passing does not establish speed
on every device. A failure is not permission to drop accessibility resources;
investigate compression, splitting, and other accessible alternatives instead.

`budget.json` is validated with JSON Schema 2020-12 / Ajv, as is the report.
The pure `checkInstall(assets, budget)` returns a report, or rejects invalid
inputs. `fixture: true` marks reports generated by this fixture checker.
To use real data later, generate a **complete** list from an actual build's
precache manifest (without duplicate revisions) and clearly distinguish
measured results from demonstration reports. This lane does not read or
modify the existing shell's Vite/Workbox configuration.

With the repository's existing dependencies installed:

```sh
npm run typecheck -w @access-main/budgets
npm run test -w @access-main/budgets
npm run dev -w @access-main/budgets
npm run test:e2e -w @access-main/budgets
```

The independent report preview uses English and French strings from catalogs.
Workbox and vite-plugin-pwa are credited as tooling only; neither endorses
the App.
